# 三维绞车收放缆准静态求解器

生产链路为 `.amodel → model_io → quasistatic.model → equilibrium → continuation → result_format → AQWR → WebGL`。原 XPBD、显式动力学和 MoorDyn 后端已经移除。可视化只读取平衡状态，不参与力学积分。

## 坐标与自由度

全部计算使用 SI 单位；Z 向上，水面 Z=0。模型明确固定的节点和 winch1/winch2 上端固定。共享节点连接的梁段组成刚体，每个自由刚体具有三个平移、三个旋转自由度。旋转向量通过旋转矩阵映射局部节点，刚体内距离始终保持不变。缆绳和网衣的独立节点具有三个位置自由度。

管梁重量由源文件空气线质量确定；全浸没浮力优先由空气/水中线质量差确定，缺失时由截面排水面积及水密度计算。开口 I 型截面只排开材料体积，封闭圆管按外径排水。无有效材料或节点连接时会报错或在元数据中明确警告，不添加隐藏的配重或约束。

## 平衡方程

每个柔性节点满足 `ΣF = 0`，每个自由刚体满足 `ΣF = 0` 与 `Σ(r × F + M) = 0`。重力、随姿态重新计算的浮力、节点外力和缆网轴向力参与同一方程。

HMPE 的初始未伸长长度由模型几何确定，轴向刚度 `EA` 来自模型材料。张力为 `T = max(0, EA × (l − L₀) / L₀)`；支持源文件明确允许受压的普通杆件。未明确单位的预张力不推断为力或应变。材料非线性、蠕变和滞回尚未表示。

细缆使用自由液面精确线段裁剪，并将浮力施加在浸没段中心。圆管沿轴线积分圆截面实际浸没面积；在全湿/全干分界处划分积分区间。浮力作用点保留轴向一阶矩，忽略横截面浮心偏移，属于细长构件近似。

网衣采用三角形轴向边或四边形边及对角线，只有拉伸刚度。它是网衣近似，不是壳单元；源 `areal` 被解释为等效边截面积，尚未进行网目尺度均匀化或网衣湿重标定。

求解使用 [SciPy 稀疏非线性最小二乘](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)，雅可比稀疏模式由节点和刚体连接图建立。优化器结束并不代表平衡合格；结果另行按实际 SI 残差验收。没有引入惯性、数值阻尼力或虚拟弹簧来抵消失衡。完全浸没且缆绳松弛时可能出现局部雅可比为零的平坦区域；求解器沿实际失衡力方向搜索更好的位置初值，并在跨越力反向时二分定位，之后仍按同一平衡阈值验收。

## 时间控制与自适应推进

`payout_m > 0` 为放缆，`payout_m < 0` 为收缆。每条独立开放绞车缆路的未伸长长度变化等于请求值，按原始段长比例分配到各段。绞车缆路不允许分叉或闭环。模型未明确连接的滑轮/导缆器不自动创建。

时间参数代表绞车运动计划，时间为 `|缆长变化| / 速度`。默认速度 1 m/min，计划时间步 3 s，初始缆长增量 50 mm；实际步长上限为 `min(初始增量, 速度 × 时间步)`。WebGL 播放倍速只影响显示。

先求初始平衡，再以上一接受解作为下一个状态的初值。发生下列情况时拒绝当前大步并减半：

- 节点跨越水面；
- 缆绳或网衣松弛/张紧集合变化；
- 浮力变化超过当前浮力的 1%（至少 10 N）；
- 非线性求解未通过平衡验收。

默认最小增量 0.1 mm；在最小增量仍不收敛时终止并报错。过渡被接受后逐渐恢复增量。固定支撑拓扑在一次计算中不改变；接触、脱钩、限位和摩擦切换需要新增显式约束模型，目前不支持。

## 验收与输出

默认独立阈值：力残差 1 N、力矩残差 1 N·m、解细化位移变化 10 μm、张力变化 1 N、浮力变化 1 N、刚体长度误差 10 nm。解变化指同一个缆长状态的重复细化，不是相邻运动状态之差。

只写入通过验收的状态。AQWR v2 保留原节点位置/张力播放布局，增加逐帧收敛信息、步长、事件标记和接受/拒绝统计。每帧外载力矩按当前构型更新，参考点为原始梁质量中心。初始平衡也经过同样验收；失败运行不会写出新结果。

## 使用与验证

```sh
python -m pip install -r requirements.txt
python -m simulation.winch_solver path/to/model.amodel \
  --payout-m -1 --initial-increment-mm 50 \
  --time-step-seconds 3 --speed-m-per-min 1 \
  --output simulation_results/retrieval.aqwr
python -m unittest discover -s tests_python
```

回归覆盖解析张力及弹性伸长、收放方向、刚体旋转与力矩平衡、固定支撑、液面裁剪与半浸没圆管、过渡自动缩步、失败不输出、AQWR 格式与模型材料单位。真实大型模型的全行程收敛与工程准确性需要另外验证。
